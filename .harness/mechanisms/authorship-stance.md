# Authorship Stance

Defines how a skill collaborates for a particular activity.

This is not provenance.

Provenance records where a finding came from.

Authorship stance determines how the current decision or specification work should proceed.

## Stances

### `owner-led`

Use when the owner already carries the relevant intent, terminology, preference, or character.

The harness extracts, structures, challenges, and scrutinizes without replacing that intent.

### `harness-proposed`

Use when material is thin or absent and the harness can productively propose a candidate.

The harness proposes; the owner corrects or accepts where the decision is theirs.

### `already-settled`

Use when authoritative input already establishes the answer.

Transcribe or apply with scrutiny rather than reopening the decision through unnecessary interviewing.

## Rule

Name the stance before beginning an activity when authorship matters.

Discovering authorship only after a proposal has entered an authoritative artifact risks turning a suggestion into an apparent owner decision.
