# Style Reference

Establishes perceptual references for the senses relevant to the current goal.

## Authority target

Follow the [Project Authority Target Contract](../../contracts/project-authority-target-contract.md). Under `spec`, edit/check the affected stable Spec scope(s). Under `repository-native`, edit/check the corresponding section of the current transient Goal Spec and relevant named native constraints. Any scope-ID, Spec Topology, reverse-dependency, or scoped identifier requirement below is `spec`-only unless the repository already uses an equivalent native identifier deliberately.


## Define

Describe what the product's visual or audio character should be judged against.

A reference provides direction without becoming an implementation recipe.

## Inputs

May consume:

- owner references
- Brainstorm findings
- screenshots
- products
- recordings
- descriptive material
- current Style specification

## Outputs

Authoritative Style references, separated by sense where appropriate.

## Owns

May modify the reference portions of:

the active Style authority target

## Authorship stance

Default:

`owner-led`

The harness may clarify, compare, analyze, and point out tensions.

It should not silently choose the product's character.

If the owner is stuck, Brainstorm ideation may generate candidates, but adoption remains an explicit Style decision.

## Method

For each relevant sense establish:

1. the reference
2. what aspect of it matters
3. what aspect does not
4. whether it is a hard constraint, directional reference, or feeling/character reference
5. any conflict with another established reference

## Modes

No separate execution modes. The reference skill establishes or revises the relevant per-sense reference; authorship stance governs collaboration.

## Approval

The reference expresses product character and is owner-led by default. The owner must accept a harness-proposed reference before it becomes authoritative; no separate lifecycle approval is required.

## Completion

Complete when:

- each relevant sense has enough direction for current Style work
- the important characteristic of each reference is explicit
- references are not interpreted as broader constraints than intended
- unresolved reference tensions are visible

## Invariants

- references express direction, not implementation
- visual and audio references may differ
- a reference does not imply owner preference beyond the aspect actually established
- do not fabricate a reference to fill an empty category
