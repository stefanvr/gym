# Style Visual

Defines what the user should see and the values that establish that visual character.

## Define

Specify the visual character required by the current goal.

This may include:

- color
- typography
- sizing
- shape
- iconography
- imagery treatment
- visual state distinctions
- visual animation character
- deliberate visual silence or sameness

Style Visual owns **what is seen**.

App owns where the element exists and when user interaction reaches it.

Tech owns how it is rendered.

## Inputs

May consume:

- Style reference
- App surfaces and interaction
- current goal
- Brainstorm findings
- existing Style specification
- existing implementation values when checking established Style

## Outputs

Authoritative visual rules, values, exceptions, and open decisions where genuinely unresolved.

## Owns

May modify visual portions of:

the affected Style Spec scope(s) selected by Spec Topology

## Method

For each visual decision establish:

- perceptual rule
- concrete value
- exception where relevant

Prefer named centralized values where reuse matters.

## Modes

No separate modes. Invoking the skill creates or revises only the visual decisions required by the current goal.

## Approval

No separate lifecycle approval is expected. Owner validation is required for genuinely new perceptual-character choices; craft values derived within an accepted direction need not create repeated checkpoints.

## Completion

Complete when:

- the current goal's relevant visual character is specified
- conditional perceptual behavior is explicit
- concrete values needed by implementation are defined
- values have one intended implementation home
- Preview can demonstrate the decision, or the inability to preview it is explicit

## Invariants

- visual structure does not replace App Surfaces
- visual values do not duplicate across implementation sources of truth
- Style does not choose rendering technology
- silence/sameness is explicit where meaningful
- future visual design is not specified beyond the current goal
