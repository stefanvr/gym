# Personal Notes

Personal Notes are local capture for reminders, todos, and ideas that the developer does not want on mainline and does not want treated as a Project backlog.

The optional file is `doc/notes.md`. It is ignored by Git, local to the developer workspace, non-authoritative, and **never loaded into agent context automatically**.

Notes are consulted only when the owner asks to capture, review, prune, or use them. A note becomes work only when the owner explicitly promotes it to a Goal; merely existing in the file gives it no priority or status.
