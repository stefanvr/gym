# Routing

This file is a compact routing index.

Route broad Project concerns to their authority orchestrator when choosing one narrow skill would be premature. Route already-understood narrow concerns directly to the owning skill. Active methods may assist either path but never become Project authority.

| Concern | Owner |
|---|---|
| Collaboration posture with the owner | Collaboration guide |
